Это небольшой репозиторий со скриптами для шахмат на Python. Скрипт main.py позволяет играть против движка Stockfish, а скрипт Stockfish-battle.py генерирует синтетические партии. Для их использования необходим движок Stockfish.
Для уставноки клонируйте репозиторий, запустите install.bat в Windows или install.sh для Linux. Путь к движку прописывается при запуске Stockfish-battle.py или main.py.
